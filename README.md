# Meu Cartão Tech

Portfólio digital responsivo com identidade visual cyberpunk neon, feito em HTML, CSS e JavaScript sem dependências de build.

## Recursos

- Perfil com foto, cargo, bio e competências.
- Temas visuais, incluindo Cyber Neon, Terminal, Blueprint, Holograma, SOC Dark Ops e Daylight IDE.
- Redes sociais e links configuráveis.
- Projetos em destaque com descrição, tecnologias, repositório e demonstração.
- Depoimentos editáveis.
- Links de comando copiáveis.
- Compartilhamento por link público e link de edição.
- Exportação de backup JSON, contato vCard e impressão/salvamento em PDF.
- Layout responsivo e suporte a preferência de movimento reduzido.

## Como usar

1. Abra index.html em um navegador ou publique o repositório usando GitHub Pages.
2. Selecione **Entrar e editar**.
3. Personalize nome, cargo, bio, foto, skills, redes, projetos e depoimentos.
4. Use **Concluir** para voltar à visualização do cartão.
5. Copie o link público para compartilhar. Guarde o link de edição em local seguro.

## Publicar com GitHub Pages

No GitHub, abra **Settings → Pages**, selecione a branch main e a pasta / (root), depois salve. Aguarde a publicação ser concluída pelo GitHub Pages.

## Armazenamento e privacidade

- O perfil é salvo no armazenamento local do navegador. Limpar os dados do navegador ou trocar de dispositivo pode remover esse perfil local.
- O link compartilhável serializa os dados do perfil no fragmento do endereço. Isso é codificação, não criptografia. Qualquer pessoa com o link pode ler os dados incluídos nele.
- O projeto não tem banco de dados, autenticação ou sincronização entre usuários/dispositivos.
- Exporte o backup JSON periodicamente e não inclua informações confidenciais.
- O conteúdo de exemplo deve ser substituído por projetos e depoimentos reais antes de divulgar o portfólio.

## Tecnologias

HTML5, CSS, JavaScript nativo e Google Fonts (Chakra Petch e JetBrains Mono).
